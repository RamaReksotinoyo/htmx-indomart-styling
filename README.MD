# HTMX Indomaret Styling 🔥

A simple unnecesary management app with Indomaret-inspired styling using HTMX and Go.

## Features

- HTMX for dynamic interactions
- Go backend
- Indomaret colors (Red, Blue, Yellow)

## Quick Start

```bash
# Clone
git clone https://github.com/ramareksotinoyo/htmx-indomart-styling.git
cd htmx-indomart-styling

# Run
go run main.go

# Open browser
http://localhost:8080
```

## Build

```bash
# Local
make build

# Run all 
make all
```
